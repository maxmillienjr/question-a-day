# Saved sources

Each file is the plain text of one fetched page, written by `tools/fetch.py`. The header gives the
URL, the fetch date, the revision (Wikipedia), the licence and the credit line; the text follows the
`---` line. Tables are flattened, one cell or row per line. Footnote markers are dropped.

- `wikipedia/`: English Wikipedia, CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/).
  Credit: Wikipedia contributors, the article named in each file's header.
- `government/`: United States government works, public domain.
